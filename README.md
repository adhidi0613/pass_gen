
## Installation Guide
Follow the installation instructions above to set up the project.

## Security
Use randomly generated passwords and avoid reusing passwords across accounts.

## Usage Tips
Choose a suitable password length and enable different character types.

## Password review reminders
Use the reminders on the main page to choose an account label and a review date. Reminders are saved in this browser only; passwords are never stored with them. Browser notifications are optional and are checked while the page is open.
